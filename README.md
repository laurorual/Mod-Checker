# Minecraft Mod Checker
A Python script to check if a Minecraft mod is client-side or server-side and organize them to use in a server.

## How to use it
1. Clone verificar_mods.py from this repository.
2. Install requests, tqdm and tomli (if using Python < 3.11) using pip.
3. Put the script inside your mods folder, make it executable and run it.

## Why use this script?
I wanted to create a server from a modpack that has 300+ mods. If we put client-side mods inside the server it crashes. This script helps detect which mods are client-side and server-side, so you can use only the ones you need.

This script was created in Brazilian Portuguese language, if you don't understand something, please use Google Translate.
